# BloomCycle

A SwiftUI interface prototype that presents menstrual-cycle phases through illustrated cards about nutritional needs and foods.

## Overview

The repository contains views for the menstrual, follicular, ovulation, and luteal phases.
Each view uses a shared card component and a custom asset palette.

## Built with

- Swift and SwiftUI
- Xcode asset catalogs

## Current scope

This is an interface prototype. The app opens the menstrual-phase screen; 
the other phase views can be explored through Xcode previews.
Cycle logging, predictions, and navigation between phases.
